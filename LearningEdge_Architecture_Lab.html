System design walkthrough · LearningEdge

One training file, the whole platform

Follow an organization admin starting extraction on a PDF or Word file. The same action crosses the Angular UI, the .NET API, Keycloak, SQL Server, Redis, RabbitMQ, the document parser, Ollama, Qdrant, and SignalR. The question generator is on the map because the contract exists. Its consumer does not generate questions yet.

The domain: LearningEdge

A multi-tenant training system. An organization owns categories, trainings, files, question banks, and exams. Identity lives in Keycloak. Course data lives in SQL Server. Searchable document meaning lives in Qdrant, one collection per organization.

  • Identitypeople, roles, approval
  • Catalogorgs, categories, trainings
  • Materialsfiles on a shared volume
  • Questionsbanks, prompts, items
  • Deliveryexams built from banks

An extract must

  • R1Put vectors in that organization's Qdrant collection only.
  • R2Start only for an OrgAdmin of that org, or a SysAdmin.
  • R3Skip a file whose Redis status is already Completed.
  • R4Let workers write Redis. Only the API speaks SignalR.
  • R5Keep a learner out of Keycloak until an admin approves them.
